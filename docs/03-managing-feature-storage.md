# Strategies for managing feature storage in ArcGIS Online

The pages in this section outline some steps you can take to manage your ArcGIS Online content 
efficiently, reducing unnecessary feature storage usage. You may find one that
works well for your use case, and they can often be used in combination
(for example, clipping a dataset and then converting it to GeoJSON).

Note: Many of the workflow examples here use <a href="https://mdlutoronto.github.io/arcgis-pro-info-tutorials-workshops/" target="_blank">ArcGIS Pro</a>, the
desktop complement to ArcGIS Online. You can <a href="https://mdlutoronto.github.io/arcgis-pro-install-license/"
target="_blank">download and install Pro on your own Windows device</a>, or
access it on
<a href="https://mdl.library.utoronto.ca/technology/computers-with-gis-software"
target="_blank">campus computers</a>.

If you aren't able to run ArcGIS Pro,
<a href="https://www.qgis.org/" target="_blank">QGIS</a> is a fine alternative.
It's free, and will run on all major operating systems (Windows, Mac, Linux). 

The Map and Data Library staff are also
happy to help you get started!
<a href="https://mdl.library.utoronto.ca/about/contact-form" target="_blank">Contact us</a>
if you have any questions.
