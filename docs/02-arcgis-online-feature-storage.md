# ArcGIS Online: feature storage

### Overview


<b>Feature storage</b> in ArcGIS Online refers to the storage used by <i>hosted
feature layers</i>. This type of ArcGIS Online item contains geographic data
represented as points, lines, and polygons, and supports the editing and
analysis tools offered by ArcGIS Online. <b>Feature storage is the
most resource-intensive, and therefore expensive, type of storage on the
platform.</b> UofT has a shared limit of 500 GB across all users.

### View your items' feature storage usage


<b>You can check how much feature storage you're using by following these steps:</b>

• Log in to ArcGIS Online (more information <a href="https://mdlutoronto.github.io/arcgis-online-log-in/" target="_blank">here.</a>)

• Click the <b>Content</b> tab.

</a>

• In the <b>Filters</b> section on the left, click <b>Layers → Feature Layers</b>.
