# When should you use ArcGIS Online?

ArcGIS Online is a tool with powerful features and unique advantages, but it's
not the only choice for doing work with digital maps or working on web-based projects. Before
you get started, consider whether ArcGIS Online is the best choice for your
project, or if you might be better served by an alternative.

### In short, ArcGIS Online is a good choice when you want to:
<ul>
<li><b>Collaborate</b> on digital projects that use small to medium-sized
datasets.</li>
<li>Create <b>interactive web maps or dashboards</b> (with the option of
displaying them publicly on the web).</li>
<li><b>Collect or edit data online</b> (for example, creating a data collection
survey and then working with the results).</li>
</ul>
...with the understanding that <b>you should not depend on the ArcGIS
Online platform being a permanent home for the project</b>.

### Consider using ArcGIS Pro or QGIS instead if:

<ul>
<li>You're working with <b>large or complex datasets.</b></li>
<li>You don't need to share your work online.</li>
<li>You're performing <b>complex analysis.</b></li>
<li>You're still <b>cleaning</b> or <b>preprocessing</b> your data (content can
be uploaded to ArcGIS Online later).</li>
</ul>

Desktop GIS software (ArcGIS Pro or QGIS) gives you more control, and (with the
exception of some ArcGIS Pro workflows that employ server-side resources from
Esri) doesn't consume ArcGIS Online storage or credits.

<b>MDL has some introductory tutorials available here:</b>

• <a href="https://mdlutoronto.github.io/arcgis-pro-info-tutorials-workshops/"
target="_blank">ArcGIS Pro</a> (created by Esri, Windows-only, accessible
through university license)

• <a href="https://mdlutoronto.github.io/qgis-mapping-spatial-analysis-intro/"
target="_blank">QGIS</a> (Free, works on Mac, Windows, or Linux)

### Geospatial coding in Python or R

Geospatial analysis and visualization packages are available for many popular
programming languages, such as Python or R. If you have coding experience, or
would like to learn, you can carry out many GIS workflows this way.

<b>The Map and Data Library offers some introductory tutorials on these topics here:</b>

• <a href="https://mdlutoronto.github.io/r-gis-intro/" target="_blank">
Introduction to GIS using R</a>

• <a href="https://mdlutoronto.github.io/python-jupyter-notebooks-geospatial-analysis/"
target="_blank">Geospatial Analysis with Python & Jupyter Notebooks</a>


### Other options for web-based projects

* If you'd like to work in ArcGIS Online but want to keep your content after
leaving the university, the
<a href="https://community.esri.com/t5/arcgis-online-public-account-community/arcgis-online-public-accounts-getting-started/ba-p/1305110" target="_blank">
free version of ArcGIS Online</a> (called a 'public account') is not tied to an
institutional subscription and may meet your needs. It's also often possible to work
in UofT's ArcGIS Online and transfer your content to a free account later.

* As an alternative to ArcGIS Online, effective web-based digital mapping projects can be
created with free web-based tools such as
<a href="https://flourish.studio/" target="_blank">Flourish</a> or
<a href="https://storymap.knightlab.com/" target="_blank">StoryMapJS</a>.

* <b>If you have web development skills (HTML, CSS, JavaScript), or would like to
learn them</b>, you could deploy your own custom digital projects, including web
maps, to a free web hosting platform such as
<a href="https://github.blog/developer-skills/github/github-for-beginners-getting-started-with-github-pages/" target="_blank">
GitHub Pages</a>. <b>For a beginner-friendly example of this, please see MDL's
<a href="https://mdlutoronto.github.io/qgis2web-github-pages/" target="_blank">
Open source web map creation with qgis2web and GitHub Pages</a> tutorial.</b>

<a href="https://mdl.library.utoronto.ca/about/contact-form" target="_blank">
Get in contact with the Map and Data Library</a>
if you'd like help in choosing the right tool for your project, or assistance
in getting started with any of these options.
